Before you start

  1. Close Metro Exodus.
  2. Keep a copy of your original MetroExodus.exe and user.cfg somewhere safe.
  3. Select the files on this page. Your originals stay unchanged until you install the downloads yourself.
Where are my files?

In Steam, open the game's Properties, then Installed Files and Browse. Select MetroExodus.exe.

Find user.cfg under %USERPROFILE%\Saved Games\Metro Exodus\<profile>\. Choose the profile you play. Launch the game once if it is missing.

Updating an older version

Select your currently patched executable to change sensitivity without patching it again. Keep the original MetroExodus.exe.sensunlock.bak made by the old tool.

If the tool reports a partial patch, restore a clean executable with your game launcher before continuing. Do not treat a partially patched file as an original backup.

Restore the original game

Close Metro. Replace the modified executable and config with your original backups. If using the old tool's backup, copy it and name the copy MetroExodus.exe.

After a game update, use the launcher's file verification to obtain the current executable instead of restoring an older backup. Reverting the config also restores any other settings saved in that backup.

3. Download and install

Download modified executable Download modified user.cfg

Save downloads to a separate folder. With Metro closed, copy them into the original folders and replace the matching files. The executable must be named MetroExodus.exe and the config user.cfg, with no download-number suffix.

Preparing or downloading files does not install them. This page cannot check whether the game is running or whether you installed the copies.

Compatibility and diagnostics

Based on the Steam Enhanced Edition patch. Other builds are untested, even if their patterns match. Partial or unrecognised files are refused.

Browsers and security scanners may still flag a generated executable. This tool does not guarantee Nexus approval.
